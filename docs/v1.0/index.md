# BigBacter v1.0
{: .no_toc}

BigBacter is a pipeline aimed at simplifying bacterial genomic surveillance.

{: .warning }
> This documents BigBacter v1.0, which uses PopPUNK for clustering. If you are running v2.0 or later, see the [v2.0 documentation]({{ site.baseurl }}/docs/v2.0/) instead — clustering, the database layout, and several parameter names have changed.
